### 1. Memory Leak Prevention (Commit 61e22f23dd)

**Issue:** 3 Maps growing unbounded causing Out-Of-Memory (OOM) crashes  
**Fix:** Added TTL (Time-To-Live) cleanup for unbounded Maps

**Impact:** Prevents gradual memory exhaustion in long-running Gateway instances

```typescript
// Pattern: TTL-based cleanup for cached entries
interface CacheEntry<T> {
  value: T;
  timestamp: number;
}

const CACHE_TTL_MS = 3600000; // 1 hour
const _cache: Map<string, CacheEntry<any>> = new Map();

function cleanupExpiredEntries() {
  const now = Date.now();
  for (const [key, entry] of _cache.entries()) {
    if (now - entry.timestamp > CACHE_TTL_MS) {
      _cache.delete(key);
    }
  }
}
```

### 2. SSRF Prevention - Three-Phase Interaction Navigation Guard (Commit e0b8ddc1a5)

**Issue:** Browser automation could be exploited for Server-Side Request Forgery (SSRF)  
**Fix:** Three-phase navigation guard prevents unauthorized navigation

**Phases:**
1. **Validation** - Check URL against allowlist/blocklist
2. **Interception** - Intercept navigation attempts
3. **Confirmation** - Require explicit confirmation for external URLs

```typescript
// Pattern: Navigation guard
async function navigate(url: string): Promise<boolean> {
  if (!isAllowedUrl(url)) {
    throw new SecurityError(`URL not allowed: ${url}`);
  }
  
  // Intercept and validate
  await validateNavigation(url);
  
  // Proceed with guarded navigation
  return await guardedNavigate(url);
}
```

### 4. TOCTOU Race Condition Fix (Commit 53dbbd065c)

**Issue:** Time-Of-Check to Time-Of-Use race condition in script execution  
**Fix:** Replaced check-then-read with atomic pinned-fd open

**Pattern:**
```typescript
// BEFORE: Vulnerable to TOCTOU
if (fs.existsSync(scriptPath)) {
  // Race window here
  const content = fs.readFileSync(scriptPath);
}

// AFTER: Atomic operation
const fd = fs.openSync(scriptPath, 'r');
const content = fs.readFileSync(fd);
fs.closeSync(fd);
```
