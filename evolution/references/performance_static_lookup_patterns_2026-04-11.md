### Pattern 1: Static Lookup Short-Circuiting

**Files:** `src/commands/doctor/channel-capabilities.ts`, `src/infra/outbound/target-normalization.ts`

**Strategy:**
```typescript
// O(1) object lookup → Lazy normalization → Plugin registry fallback
const STATIC_CHANNEL_CAPABILITIES = {
  'telegram': ['text', 'photo', 'audio', 'document'],
  'discord': ['text', 'embed', 'reactions'],
  // ... known configurations
};

function getCapabilities(channel) {
  // Fast path: static lookup
  if (STATIC_CHANNEL_CAPABILITIES[channel]) {
    return STATIC_CHANNEL_CAPABILITIES[channel];
  }
  // Slow path: plugin registry query
  return pluginRegistry.getCapabilities(channel);
}
```

**Benefits:**
- Eliminates expensive plugin registry queries for known configurations
- Preserves dynamic capability discovery for unknown channels
- Reduces startup latency for common channel types
