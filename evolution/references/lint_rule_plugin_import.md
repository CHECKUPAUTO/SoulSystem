## Overview

ESLint/Biome lint rule to automatically detect and prevent barrel file imports from plugin modules, enforcing the direct registry import pattern for performance.

## Background

Barrel file imports (importing from `index.js` of a module) defeat tree-shaking and add unnecessary runtime overhead. The codebase is migrating toward direct registry imports for O(1) lookups.

## Problem Pattern

```typescript
// ❌ Bad - Barrel import
import { somePlugin } from '../channels/plugins';
import { somePlugin } from '../channels/plugins/index';

// ✅ Good - Direct registry import
import { somePlugin } from '../channels/plugins/registry';
import { somePlugin } from '../channels/plugins/bundled';
```

### Rule Implementation (ESLint)

```javascript
// eslint/rules/no-plugin-barrel-import.js
module.exports = {
  meta: {
    type: 'problem',
    docs: {
      description: 'Disallow barrel imports from plugin modules',
      category: 'Performance',
      recommended: true
    },
    fixable: 'code',
    schema: [],
    messages: {
      noBarrelImport: 
        'Barrel imports from "{{path}}" are not allowed. ' +
        'Use direct registry import for O(1) lookup performance.'
    }
  },

  create(context) {
    const BARREL_PATTERNS = [
      /channels\/plugins\/?$/,
      /channels\/plugins\/index/,
      /\/plugins\/?$/
    ];

    return {
      ImportDeclaration(node) {
        const importPath = node.source.value;
        
        const isBarrel = BARREL_PATTERNS.some(pattern => 
          pattern.test(importPath)
        );

        if (isBarrel) {
          context.report({
            node,
            messageId: 'noBarrelImport',
            data: { path: importPath },
            suggest: [
              {
                desc: 'Use direct registry import',
                fix(fixer) {
                  const newPath = importPath.replace(
                    /\/?$|(\/index)?$/,
                    '/registry'
                  );
                  return fixer.replaceText(
                    node.source,
                    `'${newPath}'`
                  );
                }
              }
            ]
          });
        }
      }
    };
  }
};
```
