# SoulWallet — Agent économique Lightning

## Fonctionnalités

- Création de factures Lightning
- Paiement de factures
- Consultation du solde

## Configuration

```toml
[soul_wallet]
network = "regtest"  # ou "mainnet", "testnet"
data_dir = "/var/lib/soulsystem/wallet"
```

## Usage

Utilisé pour payer des APIs externes (LLM premium, stockage).
