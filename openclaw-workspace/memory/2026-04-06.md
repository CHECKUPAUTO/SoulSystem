## MCP Protocol Implementation (2026-04-06 20:23)

- **Session flow:**
  1. `initialize` → receive serverInfo (CodeWiki v1.26.0)
  2. `tools/list` → discover available tools
  3. `tools/call` → invoke specific tools
- **MCP Tools discovered:**
  - `codewiki_list_topics` — list sections in a repo

  - `codewiki_read_contents` — full content

  - `codewiki_request_indexing` — request indexing

    "protocolVersion": "2024-11-05",

  "id": 1
}
