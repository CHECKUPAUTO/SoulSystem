## Overview

This document specifies the security guards implemented in OpenClaw's gateway tool to prevent remote agents from making dangerous configuration changes.

## Critical Security Fix (Commit 13dfd633)

### Blocked Configuration Mutations

The gateway tool now explicitly blocks the following dangerous configuration patches:

1. **Dangerous Flag Enabling**
   - Auto-approve flags for privileged operations
   - Bypass confirmations
   - Debug mode activation in production

2. **Protected Execution Path Modifications**
   - Changes to `exec.path` configuration
   - Shell interpreter modifications
   - Working directory overrides

3. **Remote Plugin Activation**
   - Enabling plugins via `config.patch`
   - Plugin load path modifications
   - Plugin permission escalations

4. **Channel Configuration Changes**
   - Channel slot modifications
   - Channel load path changes
   - Channel authentication bypass

### Implementation Pattern

```typescript
// gateway-tool.ts - Security Guard Pattern
export function applyConfigMutation(
  config: GatewayConfig,
  mutation: ConfigMutation
): Result<void, SecurityError> {
  // Validate mutation against security policy
  if (isDangerousMutation(mutation)) {
    return Err(new SecurityError(
      `Mutation blocked: ${mutation.path} is protected`
    ));
  }
  
  // Apply allowed mutations
  return applySafeMutation(config, mutation);
}
```

### Fail-Closed Behavior

- Guards fail closed (deny by default)
- Any probe/validation error results in mutation rejection
- Comprehensive audit logging for all blocked mutations
