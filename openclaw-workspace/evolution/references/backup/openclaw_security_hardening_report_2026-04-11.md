## Security Patterns Identified

### Pattern: DEFENSE_IN_DEPTH
Multi-layer security with deny-by-default at each layer:
1. Network-level (Tailscale integration)
2. Gateway-level (mutation guards)
3. Tool-level (exec approval system)
4. Channel-level (DM policies)

### Pattern: ZERO_TRUST_GATEWAY
Remote gateways assumed compromised; strict allowlist for mutations.

### Pattern: USER_INTENT_PRESERVATION
Explicit user selections protected from automated overwrites.
