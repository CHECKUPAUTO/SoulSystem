## Context

Commit `c4764095f8` centralized payload normalization into `payloads.ts`, consolidating message formatting from `send.ts`, `delivery.ts`, and `message.ts`. This is the "narrow surface pattern" in action.

## Proposed Pattern: ChannelFormatter Interface

```typescript
// src/infra/outbound/formatter.ts
interface ChannelFormatter {
  format(payload: NormalizedPayload): ChannelMessage;
  validate(payload: NormalizedPayload): ValidationResult;
}

// Each channel implements this interface:
// TelegramFormatter implements ChannelFormatter
// WhatsAppFormatter implements ChannelFormatter
// DiscordFormatter implements ChannelFormatter
// FeishuFormatter implements ChannelFormatter
```

## Benefits

1. **Plug-in extensibility** — Adding Mattermost or Slack RTM becomes a new formatter, not scattered switch/case
2. **Testability** — Each formatter can be tested in isolation with property-based tests
3. **Type safety** — The interface enforces `format()` and `validate()` for every channel
4. **Consistency** — All channels follow the same contract
